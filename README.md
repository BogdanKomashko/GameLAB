# CyberToads: Rage Metro

Простий 2D-платформер про кібер-жабу, яка бореться з AI-корольовим модулем.

## 🎮 Управління

- **← →** або **A D** - Рух вліво/вправо
- **↑** або **W** або **Пробіл** - Стрибок
- **X** - Атака

## 🎯 Мета гри

**Рівень 1: Техно-тунелі**
- Зберіть 15 енергій (20 доступно)
- Дійдіть до дверей в кінці рівня
- Уникайте ворогів Robo-rat та електричних пасток
- Рівень розширено - більше платформ та перешкод!

**Рівень 2: Серце Системи**
- Дійдіть до ядра системи
- Уникайте дронів Drone-eye та падаючих блоків
- Зупиніть AI-корольовий модуль!
- Рівень розширено - більше викликів!

## 🎨 Особливості

- 3 життя
- Система очок
- 2 рівні з різними механіками
- Простий, але атмосферний дизайн

## 🚀 Запуск

Просто відкрийте `index.html` в браузері. Гра працює без необхідності встановлення залежностей.

## 📝 Примітки

Це прототип для лабораторної роботи. Гра містить базові механіки платформера та демонструє основні концепції ігрового дизайну.
